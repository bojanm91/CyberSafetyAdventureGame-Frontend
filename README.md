# CyberSafetyAdventureGame-Frontend

Next.js + Tailwind CSS frontend za početnu verziju Cyber Safety Adventure aplikacije.

## Start

```bash
npm install
npm run dev
```

## Šta sadrži

- Landing stranicu u cyber stilu
- Hero sekciju kao na Lovable primjeru
- Sekcije `Kako funkcioniše`, `Discipline` i `Dashboard preview`
- Responsive header sa mobilnim menijem
